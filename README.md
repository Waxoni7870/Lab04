# Лабораторная работа 4

Этот репозиторий содержит решения задач четвёртой лабораторной работы на циклы (`for`, `while`).

---

## 1. Диапазон в обе стороны (`range_numbers.py`)

Программа запрашивает целые числа `a` и `b`. Выводит все числа от `a` до `b` включительно: по возрастанию при `a < b`, по убыванию при `a > b`, одно число при равенстве. Вывод осуществляется по одному числу на строке.

### Проверка:
* **Входные данные:** `2`, `4`
* **Ожидаемый результат:** `2`, `3`, `4` (на отдельных строках)

---

## 2. Статистика потока (`statistics.py`)

Программа запрашивает целое `n >= 1`, а затем ровно `n` целых чисел. Находит сумму, количество положительных значений и максимум. Список не используется, максимум инициализируется первым введённым значением.

### Проверка:
* **Входные данные:** `n = 3`, числа: `-5`, `-2`, `-8`
* **Ожидаемый результат:** Сумма: `-15`, положительных: `0`, максимум: `-2`

---

## 3. Повторный ввод (`positive_input.py`)

Программа запрашивает целое число с помощью цикла `while`, пока пользователь не введёт положительное. После этого выводит его квадрат и количество отклонённых (неподходящих) попыток.

### Проверка:
* **Входные данные:** `0`, `-2`, `3`
* **Ожидаемый результат:** Квадрат: `9`, количество отклонённых попыток: `2`

---

## 4. Индивидуальный вариант: Числа, кратные 3 (`variant_2.py`)

Мой вариант: **Вариант 6 — Числа, кратные 3**.

Программа запрашивает `n >= 0`, а затем `n` целых чисел. Одним циклом находит количество и сумму значений, удовлетворяющих условию (число кратно 3). Ноль кратен любому ненулевому целому. Если подходящих чисел нет, оба результата равны нулю. Список не используется.

### Пример расчёта (контрольный набор из таблицы: $n=7$, числа `-12, -3, 0, 2, 10, 15, 20`):

* **Входные данные:**
  * $n = 7$
  * Числа: `-12`, `-3`, `0`, `2`, `10`, `15`, `20`
* **Ожидаемый результат:**
  * Количество: `4` (числа `-12`, `-3`, `0`, `15`)
  * Сумма: `0` (`$-12 + (-3) + 0 + 15 = 0$`)
